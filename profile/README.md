# profile

> 面向食品包装标示期限的辅助识读与核验系统

**轻眸识刻（QingMouFoodDate）** 是一个面向真实消费与流通场景的食品包装日期识读项目。目标是帮助消费者——尤其是中老年视弱与视障人群——以及商超仓储巡检人员，更可靠地核验包装上标注的生产日期、到期日与保质期信息。

**项目状态**：多阶段视觉识读、中式双口径期效推导与多端交互原型已完成闭环，当前正推进端云协同性能优化与生态扩展。核心算法细节与受控数据集在发明专利申请受理前不对外公开。

---

## 一、问题背景

食品包装上的日期通常印在瓶盖、罐底、封口或折角处，字号小、对比度低，工艺上有点阵喷码、激光灼刻、钢印压纹等多种形式。在真实拍摄条件下，反光、曲面、褶皱与随意摆放的角度会让这些字符更难辨认。

对视力正常的人，这只是一点不方便；对中老年视弱与视障人群，往往意味着无法独立判断手上的食品是否还在标示期限内。

现有通用文字识别工具与通用多模态大模型在这类场景下并不稳定：结果看上去合理，却可能漏掉首尾数字、读错字符或将生产批号误判为生产日期，而用户很难察觉。

---

## 二、项目目标

- **可解释**：用户能看到原图定位框、微距切片与识读依据，而不是一个黑箱结论；
- **稳定**：针对点阵断笔、微小字符与复杂包装背景进行专项优化，在真实拍摄条件下保持可靠；
- **知不确定**：信息不足或置信度偏低时明确提示补拍包装另一面或人工复核，而不是给出看似确定的错误答案；
- **边界清晰**：输出仅代表包装的客观标示状态，不替代任何专业食品安全检测。

## 四、仓库体系与知识产权说明

项目按「组织通用规约 `.github` / 产品规约与契约基准 `ProjectPRD` / 评测与申报归档 `reports` / 受控数据治理 `data` / 训练调度治理 `TrainPlatform` / 算法模型研发 `ModelTrain` / 在线推理服务 `InferPlatform` / 多端应用 `WebClient`、`MobileClient`、`WxClient`」十仓体系分仓协同，各仓职责与接口契约独立维护。

本项目坚持「先申请、后公开」原则：在核心发明专利完成申请受理前，算法方案、系统实现与数据集细节保持私有访问，本页面仅用于说明项目背景与整体架构方向。
