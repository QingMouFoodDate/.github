# 轻眸识刻

> 面向食品包装标示期限的辅助识读与核验系统

**轻眸识刻（QingMouFoodDate）** 是一个面向真实消费与流通场景的食品包装日期识读项目。目标是帮助消费者——尤其是中老年视弱与视障人群——以及商超仓储巡检人员，更可靠地核验包装上标注的生产日期、到期日与保质期信息。

**项目状态**：数据准备与原型开发阶段。核心方法与实现细节在专利申请受理前不对外公开。

---

## 问题背景

食品包装上的日期通常印在瓶盖、罐底、封口或折角处，字号小、对比度低，工艺上有点阵喷码、激光灼刻、钢印压纹等多种形式。在真实拍摄条件下，反光、曲面、褶皱与随意摆放的角度会让这些字符更难辨认。

对视力正常的人，这只是一点不方便；对中老年视弱与视障人群，往往意味着无法独立判断手上的食品是否还在标示期限内。

现有通用文字识别工具在这类场景下并不稳定：结果看上去合理，却可能漏掉首尾数字或读错字符，而用户很难察觉。

---

## 项目目标

- **可解释**：用户能看到识读的依据，而不是一个黑箱结论；
- **稳定**：在真实拍摄条件下保持可靠，而不是只在理想图片上有效；
- **知不确定**：信息不足时明确说明不确定，提示重拍或人工核对，而不是给出看似确定的错误答案；
- **边界清晰**：输出仅代表包装的客观标示状态，不替代任何专业食品安全检测。
